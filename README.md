# ItemAuction — аукцион "предмет за предмет"

Плагин для Paper 1.21.x. Игроки выставляют лоты вида "отдаю X, хочу взамен Y",
другие игроки просматривают через GUI и покупают, если у них есть нужные предметы.

## Команды

- `/ah` — открыть витрину лотов (GUI)
- `/ah create` — выставить лот: положи в левый слот то, что продаёшь,
  затем нажми на слот цены (справа) и напиши в чат предмет и количество,
  например `gold_ingot 3` — этот предмет у тебя быть не обязан, это просто
  условие для покупателя. После этого жми подтвердить
- `/ah my` — посмотреть/снять свои активные лоты
- `/ah mail` — забрать оплату, если тебя не было на сервере в момент продажи
- `/ah cancel <id>` — снять лот по номеру (себе или как админ через право `itemauction.admin`)

## Права

- `itemauction.use` — доступ к /ah (по умолчанию есть у всех)
- `itemauction.admin` — снятие чужих лотов (по умолчанию только у OP)

## Самый простой способ получить готовый .jar (без установки чего-либо)

В проекте уже лежит файл `.github/workflows/build.yml` — это инструкция для GitHub,
которая сама скачает всё нужное и соберёт плагин.

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта)
2. Создай новый пустой репозиторий (кнопка "New repository")
3. Загрузи туда содержимое папки `ItemAuction` (можно через кнопку
   "uploading an existing file" на странице репозитория — перетащи все файлы и папки)
4. Открой вкладку **Actions** в репозитории — сборка запустится автоматически
5. Через 1-2 минуты сборка завершится (зелёная галочка), зайди в неё
   и внизу страницы будет файл **ItemAuction-jar** — скачай и распакуй, внутри `ItemAuction.jar`
6. Закинь `ItemAuction.jar` в папку `plugins/` на сервере и перезапусти сервер

Это не требует установки Java, Maven или чего-либо ещё на твоём компьютере.

## Как собрать .jar локально (альтернативный способ)

Нужен **JDK 21** (Paper 1.21.x требует именно 21-ю версию Java) и **Maven**.

1. Установи JDK 21, если ещё нет:
   - Windows/Mac/Linux: https://adoptium.net/ (выбери версию 21, "Temurin")
2. Установи Maven: https://maven.apache.org/download.cgi
   (или через пакетный менеджер: `apt install maven`, `brew install maven` и т.п.)
3. В терминале перейди в папку проекта:
   ```
   cd ItemAuction
   mvn clean package
   ```
4. Готовый файл появится в `target/ItemAuction.jar`
5. Закинь `ItemAuction.jar` в папку `plugins/` на сервере и перезапусти сервер

### Если нет возможности ставить Maven локально

Можно собрать через IntelliJ IDEA (Community, бесплатная):
1. Открой папку проекта в IntelliJ как Maven-проект (он сам подтянет зависимости)
2. Справа откроется панель Maven → `Lifecycle` → `package`
3. Jar появится в `target/`

Либо есть онлайн-сборщики Maven-проектов (например, репозитории на GitHub с Actions) —
если нужно, могу расписать вариант через GitHub Actions, который соберёт jar автоматически
при загрузке проекта в репозиторий.

## Важные технические детали

- Хранение — простые YAML-файлы `plugins/ItemAuction/listings.yml` и `mailbox.yml`
- Цена/предмет сравниваются через `ItemStack.isSimilar()` — то есть зачарованная книга
  "Острота V" будет засчитана только если у покупателя есть точно такая же зачарованная книга
- Лимит лотов на игрока и названия окон — в `config.yml`
